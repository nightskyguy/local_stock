## Tips

1. **Refresh Data**: Press Ctrl+Shift+F9 to recalculate all formulas
2. **Auto-Refresh**: Tools → Options → LibreOffice Calc → Calculate → set "Automatically"
3. **Formatting**: 
   - Price columns: Format → Cells → Currency → USD
   - Percent columns: Format → Cells → Percentage
4. **Charts**: Insert → Chart → Select your data range

## Formula Reference

### Basic Formulas
- Latest price: `=PYUNO("get_quote","SYMBOL")`
- Specific date: `=PYUNO("get_quote","SYMBOL","2025-01-15")`
- High price: `=PYUNO("get_quote","SYMBOL","","high")`
- Volume: `=PYUNO("get_quote","SYMBOL","","volume")`
- Latest date: `=PYUNO("get_latest_date","SYMBOL")`

### Calculated Fields
- Portfolio value: `=Shares * Price`
- Gain/Loss: `=(Current - Purchase) / Purchase * 100`
- Daily change: `=(Today - Yesterday) / Yesterday * 100`

### Conditional Formatting

Apply conditional formatting to show gains (green) and losses (red):
1. Select the range
2. Format → Conditional Formatting → Condition
3. Condition: "Cell value is greater than 0" → Green background
4. Add another: "Cell value is less than 0" → Red background
